阵图者，代码之形也；代码者，阵图之魂也。

一、Python：御剑飞行矩阵

Python 布阵，讲究一气呵成。此阵可将剑气化为数组，一息千里：

def fly_sword(points: list[tuple[float, float]]) -> list[tuple[float, float]]:
    """将剑气按仙力矩阵归一化，供御剑飞行使用。"""
    if not points:
        raise ValueError("剑气不能为空")

    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    x_min, x_max = min(xs), max(xs)
    y_min, y_max = min(ys), max(ys)

    def norm(x: float, lo: float, hi: float) -> float:
        return (x - lo) / (hi - lo) if hi > lo else 0.0

    return [
        (norm(x, x_min, x_max), norm(y, y_min, y_max))
        for x, y in points
    ]


if __name__ == "__main__":
    trail = [(0, 0), (10, 20), (30, 60)]
    print(fly_sword(trail))  # [(0.0, 0.0), (0.33, 0.33), (1.0, 1.0)]

要点：list[tuple[...]] 注解、列表推导式、if __name__ == "__main__"，皆是御剑飞行的基本功。

二、JavaScript：召唤灵兽的符咒

JavaScript 布阵，讲究响应之快。此符可唤一只灵猫，闻声而动：

const spiritCat = {
  name: "山君",
  realm: "金丹期",
  speak() {
    console.log(`${this.name}：喵了个咪，灵气不足。`);
  },
  async fetchSpirit(api) {
    const res = await fetch(api);
    if (!res.ok) throw new Error(`召唤失败：${res.status}`);
    return res.json();
  },
};

document.querySelector("#summon-btn")?.addEventListener("click", () => {
  spiritCat.speak();
});

要点：对象字面量、模板字符串、async/await、可选链 ?.，皆是唤灵入门的七步功。

JavaScript 符箓之道 交互、呼应、即时相应
